# validation/

## Purpose
Checks that prove the work meets the stated requirement, and the recorded result
of running those checks.

## What belongs here
- Checklists per stage (e.g. the 12-folder structure check)
- Skill validation results
- Data validation notes: row counts, totals, spot checks against LEDSone
- UI validation against the AMAZON FBA.pdf page 6 reference dashboard
- Fix-and-revalidate records showing what failed, the fix, and the re-run result
- Final validation reports with an explicit PASS / FAIL per item

## What does NOT belong here
- The raw captures themselves (use `evidence/`). Reference them from here
- Feature code or dashboard markup
- A PASS recorded without the check actually having been run
- Design or requirement discussion (use `documentation/`)
